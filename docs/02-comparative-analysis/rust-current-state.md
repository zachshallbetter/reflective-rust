# Rust Current State

**Status:** Research synthesis

Rust has syntax-level macros, derives, compiler queries, const evaluation, and MIR infrastructure. The Rust Project's 2026 reflection-and-comptime goal describes an experimental reflection MVP and ongoing design/implementation work; this is not a stable language feature and does not implement this repository's proposed `core::meta` API. See the [official 2026 reflection-and-comptime goal](https://goals.rust-lang.org/2026/reflection-and-comptime.html) for the evolving upstream status. The Reflective Rust workspace remains a separate runtime-protocol implementation and does not patch or extend `rustc`.
