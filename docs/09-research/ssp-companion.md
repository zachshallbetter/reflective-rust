# Semantic Spatial Projection Companion

**Status:** Research synthesis

A Compiler Semantic Graph can act as the persistent semantic world underlying Semantic Spatial Projection. Types, modules, traits, implementations, runtime services, ownership boundaries, and workflows can become spatially navigable projections without duplicating the underlying model.

This is a design inference, not an established result of the language-comparison evidence. It should be evaluated through a prototype that maintains identity and state synchronization between compiler entities, runtime descriptors, editor selections, and spatial representations.
