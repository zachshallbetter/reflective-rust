# Constrained Intercession

**Status:** Research synthesis

Intercession should operate through declared protocols that produce compiler-checked Rust. It should not redefine borrow checking, aliasing, drop order, coherence, lifetime validity, or object layout after layout has been fixed.

Candidate protocol domains include serialization policy, schema evolution, runtime presentation, RPC adaptation, validation, documentation, and editor integration.
