# Protocol Design

**Status:** Research synthesis

A protocol definition should state:

- the semantic entities it may inspect;
- the phase in which it executes;
- the artifacts it may emit;
- the authority context used for privacy;
- the dependency fingerprint recorded for incremental compilation;
- whether runtime projection is permitted;
- the diagnostics and failure model.
