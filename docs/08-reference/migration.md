# Migration from Derive Macros

**Status:** Research synthesis

Existing derive ecosystems provide a practical migration path. Semantic reflection should initially reproduce high-value derive use cases while reducing token-level parsing, attribute duplication, and fragile generated-code diagnostics. Compatibility shims can preserve existing traits and schemas.
