# Continuations and Resumption

**Status:** Research synthesis

A reflective continuation must have a compiler-certified representation and resume only at valid safepoints. Mutation requires capability checks and type validation. Redirecting arbitrary instruction pointers or fabricating stack frames is outside the safe model.
