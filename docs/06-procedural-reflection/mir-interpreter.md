# MIR Interpreter Strategy

**Status:** Research synthesis

Miri and rustc MIR interpretation demonstrate that Rust already has machinery for typed execution over MIR-like structures. A research prototype could retain selected locals, basic blocks, and call frames in a reflectable interpreter while using ordinary compiled code outside the domain.
