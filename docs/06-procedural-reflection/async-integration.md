# Async and Generator Integration

**Status:** Research synthesis

Async lowering already transforms functions into explicit state machines. This makes async tasks a promising bounded domain for procedural reflection: states, suspended locals, wake relationships, and resumption points can be represented explicitly, subject to pinning and borrow invariants.
