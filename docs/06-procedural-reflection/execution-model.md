# Execution Model

**Status:** Research synthesis

The viable Rust path is an explicit reflectable execution domain implemented through an interpreter, retained MIR, generated state machine, or effectful coroutine runtime. Arbitrary optimized native frames cannot reliably preserve source-level locals, control flow, or resumable continuations.
