# Plugin Systems

**Status:** Research synthesis

A reflected plugin ABI should be generated from semantically verified interfaces. Runtime discovery may use linker sections, explicit registries, or generated manifests. ABI stability, ownership transfer, panic boundaries, and version negotiation must be explicit rather than inferred from type names alone.
