# Serialization Projection

**Status:** Research synthesis

A serialization metaprogram should consume semantic field information, attributes, generic predicates, and visibility context, then emit ordinary trait implementations or schema descriptors. The compiler must reject generated code that violates coherence or accesses private representation outside its authority context.
