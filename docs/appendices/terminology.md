# Terminology Control

**Status:** Research synthesis

Canonical terms should not be replaced casually. In particular:

- use **semantic reflection**, not "advanced macros";
- use **runtime projection**, not "runtime compiler reflection";
- use **metaobject intercession** only for declared protocols;
- use **procedural reflection** only when causal connection and resumption are present;
- use **reflection snapshot** for the frozen observed semantic world;
- use **phase-aware query** when availability depends on compiler analysis.
