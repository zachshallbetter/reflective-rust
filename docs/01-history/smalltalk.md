# Smalltalk and Image-Based Development

**Status:** Research synthesis

Smalltalk contributes two durable ideas: programs are live object graphs, and development tools are written in and operate on the same object system. Rust cannot simply adopt an image model without changing deployment assumptions, but it can recover part of the benefit through stable semantic identities and inspectable runtime projections.
